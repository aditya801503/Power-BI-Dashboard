# Power-BI-Dashboard
# 📊 Microsoft Sales Performance Dashboard (Power BI)

## 📌 Project Overview
This Power BI dashboard provides a detailed analysis of Microsoft’s sales performance.  
It helps in understanding business growth, regional revenue trends, product-wise profitability, and market opportunities.

The dashboard is designed for **business managers, data analysts, and decision-makers** to track KPIs, optimize product strategies, and improve revenue performance using real-time insights.


## 🎯 Key Insights Covered
✔ Total Sales, Profit, and Profit Margin  
✔ Region-wise and Category-wise Revenue Comparison  
✔ Top-Performing and Least-Performing Products  
✔ Monthly & Year-over-Year (YoY) Growth Trends  
✔ Interactive Filters: Region, Product Category, Month  


## 📈 Dashboard Features
| Feature | Description |
|---------|-------------|
| KPI Cards | Shows Total Sales, Profit, Profit % |
| Trend Analysis | Monthly and yearly revenue trends |
| Product Analysis | Top and low performing products |
| Region Performance | Sales comparison by country/region |
| Interactive Filters | Dynamic insights using slicers |


## 🛠 Tools & Technologies Used
| Tool | Purpose |
|------|---------|
| Power BI | Dashboard development & data modeling |
| Power Query | ETL & data cleaning |
| DAX | KPI calculations & insights |
| Excel | Raw data formatting |


## 🚀 How to Open
1. Download the `.pbix` file from this repository  
2. Open using **Microsoft Power BI Desktop**  
3. Interact using filters and slicers
